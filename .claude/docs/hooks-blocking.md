## Blocking Hooks (exit 2 — stops the write)

| Hook | Blocks |
|------|--------|
| `block-git-push.sh` | `git push` — Claude cannot push; user always pushes manually |
| `check-write-via-bash.sh` | Writing a project file (`.cs`, `.asmdef`, `.unity`, `.prefab`, `.asset`, `.meta`, …) through Bash — redirection, `tee`, `sed -i`, `cp`/`mv`. Every content hook is registered on `Edit\|Write` and never sees a Bash command, so this is the channel that would silently skip all of them. Use `Write`/`Edit`. `/tmp` scratch paths are exempt |
| `block-scene-edit.sh` | Direct editing of `.unity`, `.prefab`, `.asset` files |
| `guard-editor-runtime.sh` | `UnityEditor` namespace in runtime code without `#if UNITY_EDITOR` |
| `check-no-monobehaviour-in-services.sh` | Three checks in `_Framework/` / `Games/Abstracts/` / `Games/Concretes/`. Check 1 blocks `class FooHandler : MonoBehaviour` (Handler must be pure C#) and Check 2 blocks `class FooModule : ScriptableObject` (Module must be a static installer) — both via inheritance regex, unchanged. Check 3 blocks MonoBehaviour/domain `UnityEngine` usage, but is judged **structurally** now (Card 0: an own `[SerializeField]` field and/or a Unity lifecycle callback), not by filename suffix — a class with neither is flagged regardless of its name, and a class with either is allowed regardless of its name. Beyond Card 0, Check 3 no longer blocks on the mere presence of `using UnityEngine`: a pure-C# file whose only `UnityEngine` surface is **math value types** (`Mathf`, `Vector2/3/4`, `Quaternion`, `Color`, `Rect`, `Bounds`, `Ray`, `Plane`, `Matrix4x4`) or **`Debug` logging** is allowed (solid-oop.md Tier 3 "math types allowed"; Module null-guards call `Debug.LogError`). It blocks only when the file references real engine/scene/asset/input/time API (`SceneManager`, `Transform`, `GameObject`, `AudioSource`, `Physics`, `Input`, `Time`, `Resources`...), matched against comment/string-stripped source (shared regex `UNITY_ENGINE_LEAK_RE` in `_lib.sh`). Filename exemptions from Check 3 are narrowed to only the structurally-undetectable pure-C# categories: `Handler`/`Loader`/`Dal`/`Client`/`Extensions`/`Installer`/`Scope` — `Loader`/`Dal`/`Client` are Tier 4 swappable-backend implementations (architecture.md Card 2.1, e.g. `ISceneLoader`→`NormalSceneLoader`, `ISaveLoadDal`→`LocalSaveLoadDal`), `Extensions` are static extension classes, `Installer`/`Scope` are VContainer wiring types. `*Events` files and ScriptableObject config families (`*Configuration`/`*Config`/`*Catalog`/`*Definition`) remain exempt. Path-based exclusion for Editor/third-party/test code is handled separately by `should_skip_path()` in `_lib.sh`. Editor-role files (`*Inspector`/`*Editor`/`*Drawer`) are no longer exempt by filename alone — they must live under an actual `Editor/` folder or be `#if UNITY_EDITOR`-guarded to be exempt, closing a prior false-positive/false-negative gap. |
| `check-input-system.sh` | Legacy `Input.GetKey` / `Input.GetAxis` API |
| `check-vcontainer-singleton.sh` | Static singleton patterns outside of `EventBusAccessor` |
| `check-unity-event.sh` | `UnityEvent`, `UnityEvent<T>`, `using UnityEngine.Events` |
| `check-time-scale.sh` | `Time.timeScale =` assignment — use IEventBus + PauseService instead |
| `check-enum-byte-base.sh` | `enum` without `: byte` base in ECS component or IEvent files — use `ushort` if 255+ values needed |
| `guard-critical-files.sh` | Edits to `AppScope`, `InputService`, `*Installer`, `EventBus`, `AppModules`, `ConfigCatalog`, `.asmdef` — deny-then-allow gate (first attempt blocks and demands investigation, retry passes); creating a brand-new file is never blocked; `*Installer` also exempts `TestScopes/`, `EditModeTest/`, `PlayModeTest/` paths |
| `check-config-protection.sh` | Modifications to `.asmdef`, `.claude/settings.json`, `.inputactions`, `manifest.json` — **exceptions: test assemblies (`EditModeTest`, `PlayModeTest`), and *creating* a brand-new `.asmdef`** (only edits to existing assembly wiring are blocked) |
| `gateguard.sh` (PreToolUse) | Edit/Write on any C# file that has not been read in the current session |
| `guard-gate-cleared.sh` (PreToolUse) | Agent spawn blocked if `.claude/state/gate-cleared` is missing — Director Gate must be shown and `go` received before spawning any coder/fixer/committer agent |
| `guard-pipeline-direct-work.sh` (PreToolUse Edit\|MultiEdit\|Write\|Bash) | Closes the gap `guard-gate-cleared.sh` leaves open: a cleared gate only proves the gate was shown, not that a pipeline agent was actually spawned afterward. Blocks direct `Edit`/`MultiEdit`/`Write` to `_GameFolders/Scripts/**/*.cs` and direct `git commit` while `.claude/state/gate-cleared` exists AND `.claude/state/subagent-depth` is 0 (no subagent currently running) — i.e. the main session doing the coder's or committer's job itself instead of spawning it. Depth counter is maintained by `agent-start-log.sh` (+1 on Agent spawn) / `agent-stop-log.sh` (−1 on Agent completion). Escape valve: `.claude/state/pipeline-override` (one-line reason, consumed once) for explicit user-approved bypasses — visible/auditable, not silent. |
| `guard-reviewer-order.sh` | Codex installed and no `.claude/state/codex-reviewed` marker → blocks `unity-reviewer` agent spawn; Codex review required first. |
| `guard-sparc-approved.sh` (PreToolUse) | Coder agent spawn blocked if `.claude/state/sparc-approved` is missing — SPARC gate must fire and `go` received before spawning `coder` or `unity-coder` |
| `block-projectsettings.sh` (PreToolUse Edit\|Write) | Direct edits to `ProjectSettings/*.asset`, `Packages/manifest.json`, `Packages/packages-lock.json` — use the Unity Editor or Package Manager instead. |
| `check-ls-grep.sh` (PreToolUse Bash) | `ls \| grep` / `ls \| awk` / `ls \| sed` patterns — use `tree` for directory listings instead |
| `block-graph-direct-read.sh` (PreToolUse Read) | Direct `Read` of `.claude/graph/graph.json`, `scenes.json`, or `prefabs.json` when `hybrid_graph: true` — use `/knowledge-graph` subcommands or `mcp__graph_mcp__*` tools instead |
| `check-domain-folder-structure.sh` (PreToolUse) | **Fail-closed** path check on EVERY write (not just `.cs` — an `.asmdef` is how an illegal folder gets born). Any first segment under `Scripts/` outside `Games\|Tests\|Editors`, any first segment under `Scripts/Games/` outside `Abstracts\|Concretes\|Ecs`, a file at the root of `Scripts/`; plus layer names (`Service(s)/`, `Provider(s)/`, `Controller(s)/`, `View(s)/`, `Manager(s)/`, `Interface(s)/`, `Config(s)/`) and catch-alls (`Core/`, `General(s)/`) as the **first** folder under `Games/Abstracts\|Concretes/`; also a `.cs` file with no domain folder at all. Never inspects below the domain — `Players/Services/` is legal |
| `check-no-throwaway-editor-script.sh` (PreToolUse Edit\|Write) | One-shot Editor C# scripts: a `.cs` path under `Editor/(Temp\|Tmp\|Scratch\|OneShot\|Throwaway)/`, or content marked disposable (`delete this file once…`, `throwaway`, `temporary wiring helper`, `EditorTemp`). Do the work through MCP (`manage_gameobject`, `manage_components`, `manage_asset`) instead; not knowing the MCP parameter shape is not a reason to write C# — read the tool schema. Genuine bulk `AssetImporter` work belongs in a **permanent** tool under `Assets/Editor/`. Escape valve: one-line reason in `.claude/state/editor-script-override` |
| `check-architecture-doc.sh` (PostToolUse) | A **malformed** `Concretes/<Domain>/ARCHITECTURE.md`: over 40 lines, missing/reordered/extra `##` headings against `## Purpose` / `## Boundary` / `## How to extend` / `## Gotchas`, no H1, any class-name symbol (`Module` suffix exempt), or the file placed under `Abstracts/` or directly under `Concretes/`. **PostToolUse — the file is already written; exit 2 is corrective feedback, not prevention.** The missing-doc case is a warning, see `hooks-warning.md` |
