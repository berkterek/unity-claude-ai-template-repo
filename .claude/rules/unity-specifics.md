# Unity-Specific Rules

This file has been split into focused rule files:

- `unity-lifecycle.md` — Editor guards, platform defines, lifecycle order, threading, Time, component attributes, `.meta` files
- `unity-async.md` — UniTask, no coroutines, fire-and-forget, CancellationToken, DontDestroyOnLoad
- `unity-input.md` — New Input System, InputView pattern, action map switching
- `unity-prefabs.md` — Prefab rules, new GameObject() forbidden, Destroy() rules, variants, folder structure, logic/visual separation, third-party duplication
