# R3 (Cysharp) — Kullanım Paterni

## Namespace
```csharp
using R3;
using R3.Triggers; // MonoBehaviour trigger extension'ları
```

## R3 Nedir?

Cysharp'ın UniRx'e halef reactive extensions kütüphanesi. `Observable<T>` stream'leri ile olay tabanlı veri akışı sağlar. UniTask ile tam entegreli çalışır.

---

## Subject — Manuel Event Stream

```csharp
// Veri yayınlayan subject
private readonly Subject<int> _onCoinsChanged = new();
public Observable<int> OnCoinsChanged => _onCoinsChanged;

// Yayınla
_onCoinsChanged.OnNext(newAmount);

// Tamamla / temizle
_onCoinsChanged.OnCompleted();
```

---

## ReactiveProperty — Değişken + Stream

```csharp
private readonly ReactiveProperty<int> _health = new(100);
public ReadOnlyReactiveProperty<int> Health => _health;

// Değer güncelle
_health.Value = 80;

// Abone ol
_health.Subscribe(hp => UpdateHealthBar(hp)).AddTo(disposables);
```

## Subscribe ve Dispose Yönetimi

### CompositeDisposable ile (Plain C# servis)

```csharp
public sealed class PlayerService : IPlayerService, IInitializable, IDisposable
{
    private readonly CompositeDisposable _disposables = new();

    public void Initialize()
    {
        _someObservable
            .Subscribe(OnValueChanged)
            .AddTo(_disposables);
    }

    public void Dispose() => _disposables.Dispose();
}
```

### MonoBehaviour — AddTo(this)

```csharp
public sealed class HealthView : MonoBehaviour
{
    [Inject] private IPlayerService _playerService;

    private void Start()
    {
        _playerService.Health
            .Subscribe(hp => _healthText.text = hp.ToString())
            .AddTo(this); // MonoBehaviour destroy olunca otomatik dispose
    }
}
```

## Temel Operatörler

```csharp
// Filtreleme
observable.Where(x => x > 0)

// Dönüştürme
observable.Select(x => x * 2)

// Tekrarı engelle
observable.DistinctUntilChanged()

// Kısıtlama
observable.Take(5)
observable.Skip(1)

// Birleştirme
Observable.Merge(stream1, stream2)
Observable.CombineLatest(stream1, stream2, (a, b) => a + b)

// Geciktirme / throttle
observable.Debounce(TimeSpan.FromMilliseconds(200))
observable.ThrottleFirst(TimeSpan.FromSeconds(1))

// Hata yönetimi
observable.Catch<int, Exception>(e => Observable.Return(0))
```

## UniTask ile Entegrasyon

```csharp
// Observable'ı await et (ilk değeri bekle)
int value = await observable.FirstAsync(ct);

// Observable'ı UniTask'a dönüştür
await observable.ToUniTask(cancellationToken: ct);

// UniTask'ı Observable'a dönüştür
Observable.FromAsync(ct => LoadDataAsync(ct))
```

## MonoBehaviour Trigger Extension'ları

```csharp
using R3.Triggers;

// Update stream
this.UpdateAsObservable()
    .Subscribe(_ => CheckInput())
    .AddTo(this);

// Trigger / Collision
this.OnTriggerEnterAsObservable()
    .Where(col => col.CompareTag("Player"))
    .Subscribe(col => OnPlayerEnter(col))
    .AddTo(this);

// Mouse / Pointer
this.OnPointerClickAsObservable()
    .Subscribe(_ => OnClick())
    .AddTo(this);
```

## Bu Projedeki Kullanım Kuralları

- R3 stream'leri **servis katmanında** tanımlanır, View'lar abone olur — tersi değil
- `Subject` ve `ReactiveProperty` her zaman `private` — dışarıya sadece `Observable<T>` ya da `ReadOnlyReactiveProperty<T>` expose edilir
- Her subscription mutlaka `AddTo(disposables)` veya `AddTo(this)` ile dispose zincirine eklenir — subscription leak en yaygın hatadır
- `IEventBus` ile çakışmayacak şekilde kullanılır: cross-module iletişim → `IEventBus`, modül içi reaktif state → R3
- Hot path'te (Update içinde) `UpdateAsObservable()` yerine direkt `Input` okuma tercih edilir — observable overhead'inden kaçınmak için
