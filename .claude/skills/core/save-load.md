# SaveLoadSystem — Usage Pattern

**The rules live in `.claude/rules/save-load.md` (9 cards). Read that first.** This file is the API surface
only; it deliberately does not restate the rules, because the version of this skill that did restate them
drifted out of sync with the framework and described five methods that do not exist.

## Location

`Assets/_Framework/SaveLoadSystems/`
Assembly: `FrameworkSaveLoadSystems` · Namespace: `Framework.SaveLoadSystems`

Generated by `/setup-project` Step 4 — never hand-written per project.

## Structure

```
ISaveLoadDal       → storage abstraction (Tier 4) — the only place File / JsonConvert appear
ISaveLoadService   → the API game code injects (Tier 3)
SaveLoadService    → ISaveLoadService implementation, delegates to ISaveLoadDal, logs via DLog
LocalSaveLoadDal   → ISaveLoadDal implementation using File + Newtonsoft.Json under persistentDataPath
```

`LocalSaveLoadDal` writes one JSON file per key. It does **not** use PlayerPrefs, and there is no separate
`JsonUtility` path for Unity objects — one serializer, one storage mechanism.

## API Surface

```csharp
public interface ISaveLoadService
{
    void Save<T>(string key, T data);
    T    Load<T>(string key);
    bool HasKey(string key);
    void Delete(string key);
}
```

Four methods. That is the whole surface.

## Usage

```csharp
public sealed class ScoreService : IScoreService, IInitializable
{
    private readonly ISaveLoadService _saveLoad;
    private readonly ScoreConfiguration _config;
    private readonly ScoreModel _model;

    public ScoreService(ISaveLoadService saveLoad, ScoreConfiguration config, ScoreModel model)
    {
        _saveLoad = saveLoad;
        _config   = config;
        _model    = model;
    }

    public void Initialize()
    {
        if (_saveLoad.HasKey(SaveKeyHelper.SCORE))
        {
            var data = _saveLoad.Load<ScoreSaveData>(SaveKeyHelper.SCORE);
            _model.Best = data.Best;
            return;
        }

        _model.Best = _config.StartingBest;
    }

    public void Persist()
    {
        _saveLoad.Save(SaveKeyHelper.SCORE, new ScoreSaveData { Best = _model.Best });
    }
}
```

Always inject `ISaveLoadService`. Never reference `SaveLoadService` or `LocalSaveLoadDal` from game code —
`check-save-load.sh` blocks the direct-backend route with exit 2.

## Registration

Already wired by `SaveLoadModule`, which `AppModules.Install` calls second (right after `EventBusModule`,
because modules read persisted state in `Initialize()`):

```csharp
builder.Register<LocalSaveLoadDal>(Lifetime.Singleton).AsImplementedInterfaces();
builder.Register<SaveLoadService>(Lifetime.Singleton).AsImplementedInterfaces();
```

## Adding a Storage Backend

Write a class implementing `ISaveLoadDal` (e.g. `CloudSaveLoadDal`) and change the one `Register` line in
`SaveLoadModule`. `SaveLoadService` and every consumer stay untouched — that is the test of whether the DIP
boundary is in the right place (`rules/architecture.md` Card 2.1).

## Logging

Save/load operations log under `LogTag.SaveLoad`. `Log` and `Warning` are tag-filtered and `_enabledTags`
ships with `General` only, so enable the tag to see them:

```csharp
DLog.Enable(LogTag.SaveLoad);
```

`DLog.Error` is neither filtered nor stripped — see `rules/logging.md` Card 4.

## Known Gaps

None in the generated `LocalSaveLoadDal` as of 2026-09-02 — the atomic write (Card 7) and the
`JsonException` fallback (Card 8) both landed in `/setup-project` Step 4.

Two things that are still on you:

- **A project generated before that date keeps the old body.** Check the DAL, do not assume.
- **`HasKey` true + `Load` null is a reachable state** once Card 8 is in place: the file exists, so
  `HasKey` says yes, but the content did not deserialize and the fallback returned `default`. The read
  path must null-check the `Load` result and fall through to the domain's own default — see
  `rules/save-load.md` Card 6. Trusting `HasKey` alone turns a corrupt save into a
  NullReferenceException, which is further from the cause than the exception it replaced.

A hand-written `ISaveLoadDal` carries Card 8 itself. Card 7 does not port to every backend and a backend
that cannot offer the atomic swap says so in its own class.
